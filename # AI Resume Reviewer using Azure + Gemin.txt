# AI Resume Reviewer using Azure + Gemini

# Project Overview

AI Resume Reviewer is a simple AI-powered web application that helps users improve their resumes using Azure AI services and Gemini API.

The application allows users to upload a resume PDF and receive AI-generated feedback such as:
- Resume strengths
- Resume weaknesses
- Missing skills
- ATS optimization suggestions
- Formatting improvements
- Better wording recommendations

This project is beginner-friendly and focuses on learning:
- AI API integration
- Azure cloud services
- Python development
- File handling
- Prompt engineering

---

# Main Goal

Build a simple but impressive AI-powered application using:
- Python
- Streamlit
- Azure AI services
- Gemini API

without using overly complex technologies.

---

# Project Workflow

```text
User uploads resume PDF
        ↓
Azure Document Intelligence extracts text
        ↓
Gemini API analyzes resume
        ↓
AI-generated feedback displayed to user
```
